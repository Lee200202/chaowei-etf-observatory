## 工具協作狀態機

採四個專職步驟，不為增加 agent 數量而多次呼叫模型：

1. 判讀需求：本地型別解析器處理已支援規則、中文數字與追問；不明確且使用者已開 Gemini 時，才請模型轉成白名單 JSON。
2. 查核資料：固定本站 ETF／日 K／配息／融資／法人資料路徑，重用五分鐘快取；只取確認收盤，不把盤中暫時棒拿來確認歷史訊號。
3. 量化計算：共用原帳本、費稅、股利、成交時點與基準；模型不執行程式。每階段用 performance.now 記錄真實毫秒，不保證30ms。
4. 解讀核對：Gemini 可解釋結果，公開搜尋用 Google Search grounding；報酬與回落比較先和引擎數字核對，百分比及保證性敘述再過本地核對。失敗保留原計算卡，不重試到得到漂亮答案。

這是有狀態、具工具邊界的協作流程，並非多個模型同時自主交易。未引入 LangChain 的瀏覽器／GAS 不相容執行依賴；日後若改用 Node 後端，可沿用同一 JSON 協定接 LangGraph。單次對話共用22秒外部等待預算；本機結果先顯示，模型逾時不清掉圖表。顯示伺服器耗時及實際 token 用量，不公開模型內部思考。

## 支援的研究

自然語言回檔分批：預設繼承標的與本金（無設定時0050／120萬）、近五年、40%核心、剩餘3批、前240根確認K的高點下跌10%開始、同輪高點每再跌10%加一批、持有不設停利；可說無底倉、分六批、改本金、賺20%出場。顯示代填值及完整規則。跌幅不是以每筆成交價複利遞減。

可詢問三組 ph10 策略、同區間11組比較、RSI／MACD／威廉／均線的日 K 技術訊號、指標與操作教學、ETF確認收盤／法人。ATR只有波幅定義，缺買賣方向時先追問，不擅自生成策略。技術訊號用完整暖機後的交叉，不取未來價格；比較排行是同段歷史內排序，不冒充樣本外驗證。提及訓練／驗證時提供既有固定訓練工具入口，不用全期間排名冒充驗證。

回檔與支援的預設可帶入白板：標的、參數、日期、本金及定投12期保留；白板的次日收盤與對話的所選成交模型仍可能不同，需重新回測。無底倉0%、六批不能被原進階策略10%／四批限制改掉。不支援的上游條件不能被默默忽略；目前只有三組進階與對話回檔可限制衛星加碼。

## Gemini 與公開搜尋

只接受伺服器代理。指令碼屬性 `GEMINI_API_KEY` 必填；`GEMINI_MODEL` 選填，預設 `gemini-3.5-flash-lite`；`GEMINI_SEARCH_ENABLED=false` 可停用搜尋。預設依本輪 Google 官方文件選擇；不沿用新專案可能無法使用的2.5模型假設。API 用固定 Google 端點與 `x-goog-api-key` header，金鑰不放前端、URL、LocalStorage或模型提示。

Google 會員 ID token 先核對專案、issuer、期限，再透過 Firebase accounts:lookup 驗證與比對 Google provider、停用／撤銷狀態。付費呼叫以會員每日10次、全站每日60次、送出間隔20秒、鎖保護額度；未登入不能消耗站長 Gemini 額度。輸入長度有上限，不支援動態eval、任意URL抓取、SQL或後台管理工具；前端正則只改善提示，不能代替後端權限。

外部模型預設不勾選，使用者開啟後才送問題與摘要到 Google；不送會員email、token或金鑰到模型。公開搜尋只在明確查網路時使用，列來源及回應時間；沒有來源不能宣稱已查得最新行情。Google搜尋建議用隔離且禁腳本的 iframe 顯示，回覆文字用textContent，來源只接受https。

## 回饋

可在對話室填問題／建議，下載到自己裝置，或登入後點「送給站長」。送出時才寫入既有潮位資料庫的私人「網站回饋」工作表，欄位為時間、編號、去識別會員代碼、分類、文字、ETF、版本，不附整段對話。每日每會員3次、全站100次；內容以純文字寫入，開頭試算表公式符號加引號防止執行。若資料庫或網路不可用，明講未確認送達並提供下載，不假稱寄出郵件。
