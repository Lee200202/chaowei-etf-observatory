# 八大行庫全市場總額：私人資料庫

- 來源：HiStock「八大官股銀行／公股行庫買賣總金額走勢圖」的 `SumMoney` 與 `Price`，不是下方逐檔 Top 30。
- 2026-10-23 驗收使用者 CSV：123 個交易日，2026-04-27 至 2026-10-22，日期無重複、數值無空缺。當晚重抓仍為 123 日，新增 0 日。
- 單位：買賣總金額為**億元**，正數買超、負數賣超；`Price` 是加權指數。圖表時間戳以 UTC 午夜直接取日期。
- 儲存：Apps Script 的「潮位資料庫」私人試算表，分頁「八大行庫總額」。不放入 GitHub Pages 快照，不作逐檔 ETF 權重與公開分數。
- 排程：Apps Script `setupBankHistory` 安裝台北時間每日約 20:00 的觸發器，`appendBankHistory` 只在週一至週五抓取。一天先記錄一次嘗試；失敗留在「更新紀錄」，當日不重試。時鐘觸發器由 Google 安排，並非保證 20:00:00 整秒執行。
- 合併：新日期加入舊資料；來源修正同一日期時更新該列；來源 `All` 只保留近期資料，不刪已累積的舊日。
- 驗收：執行 `npm run test:bank` 檢查圖表解析、UTC 日期與圖表缺失時中止；首次執行 `appendBankHistory` 後，以 `storeStatus` 及試算表讀回列數和首末日期。

此分頁僅供使用者內部研究。現有 HiStock 往來文字是商務授權初步說明，未見正式簽署及公開展示範圍；對外圖表、數值、權重需待授權確認。
