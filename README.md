# 潮位 ETF 觀測所

以證交所盤後資料觀察 ETF 價格水位、台灣加權指數與成交股數，並結合期交所布蘭特原油期貨（BRF）近月結算價及中央銀行 USD/TWD 日資料。使用者可選擇觀察窗、黃金分割或等距刻度、自訂權重，並開啟 MA、布林通道、MACD、RSI、KD。分數是歷史相對位置，不是報酬預測。

- GitHub Pages：<https://lee200202.github.io/chaowei-etf-observatory/>
- Apps Script：同一份前端，見下方「Apps Script」。

## 資料與限制

- ETF 名錄來自[證交所 ETF e添富](https://www.twse.com.tw/zh/ETFortune/products)，`npm run catalog:update` 更新，含 009816 等新掛牌商品。上櫃 ETF 尚未加入。
- 日 K 來自證交所 `MI_INDEX`（type=0099P，每日收盤行情 ETF 表），大盤來自 `FMTQIK`。`npm run history:update` 把約十年（2016-10 起）的資料寫成 `pages-data/history/<代號>.json` 與 `market.json`，之後每天只補新的交易日。網頁開一檔 ETF 只讀一個檔案；快照落後最新交易日時，才向證交所補當月資料（每檔最多一次請求）。
- 分割／反分割由證交所的漲跌價差推算（前一日收盤 ÷ 當日參考價），之前的價格依比例還原；成交股數保留交易所公布的實際股數，調整紀錄列在檔案的 `adjustments`。新上市 ETF 只有上市後資料。含息口徑尚待校驗。
- 布蘭特參考線為臺灣期貨交易所布蘭特原油期貨（BRF）近月每日結算價，新台幣／桶，資料來源 FinMind（`npm run brent:update`，2018-07 起；近月＝當日一般交易時段有結算價的最近單一月份契約）。依 FinMind 條款僅作非商業用途並標示 FinMind。舊的 EIA 現貨序列封存在 `pages-data/brent-eia.json`，不再更新。USD/TWD 來自中央銀行開放資料。網頁各保留最近約 2,700 筆。快照逾 14 天不計分。DXY 尚未提供；盤中價的公開展示開關預設關閉。
- 富果盤中報價的伺服器串接已備妥：金鑰只放在 Apps Script 指令碼屬性 `FUGLE_API_KEY`，另須在核對公開展示授權範圍後設定 `FUGLE_PUBLIC_DISPLAY_ENABLED=true` 才會對訪客顯示。每檔報價快取 240 秒、前端每 5 分鐘檢查一次；盤中當日 K 與水位均標為暫值，盤後歷史資料仍取自證交所。未啟用時不顯示盤中價。
- 量能採成交股數歷史百分位；使用者須自行選擇高量或低量分高。分數 0–5、到小數一位，越高代表越適合加碼：ETF 與大盤在區間低處分高；原油價格越低分越高；台幣越升值（USD/TWD 越小）分越低，使用者可在匯率卡反轉方向。
- 歷史行情與市場資料是每日靜態快照。網站每 5 分鐘檢查小型版本清單，變更時才讀新檔；同版資料由瀏覽器 HTTP 快取保留，切換 ETF 不會重複向交易所抓取十年資料。
- 市場刻度每 5 分鐘經 Apps Script `getLiveMarket`（Pages 以 JSONP `?api=live` 呼叫）取最新資料，整包快取 4 分鐘：盤中（09:01–16:00）讀證交所 `MI_5MINS_INDEX` 的加權指數與 `MI_5MINS` 的累計成交量；布蘭特先讀潮位資料庫「布蘭特期貨近月」分頁，缺少時由 `brfNear_` 經 FinMind 讀期交所 BRF（指令碼屬性 `FINMIND_API_TOKEN` 只放在請求標頭）；央行匯率直接讀官方來源。BRF 是每日結算價、不是盤中報價，央行匯率於收盤後公布。
- 盤中量能只和過去交易日「同一時刻」的累計成交量比較（`pages-data/history/intraday-volume.json`，每 5 分鐘一個刻度、約 600 個交易日，`npm run intraday:update` 每日補一天），不拿上午累計量對照整日成交量；同時段樣本不足 20 日時暫停量能計分。
- 成交量可選「原始張數」（交易所公布）或「拆分換算」（分割前乘上分割比例，方便前後比較）；預設原始張數。

## 策略回測與比較

引擎在 `worker/strategy-engine.js`（不依賴頁面，`npm run test:engine` 離線驗證）。

- 資金：所有策略拿到同一筆資金基數 C；未投入的現金按「閒置資金年利率」每日計息。N 預設「自動」＝回測期間的月數（5 年約 60 期），也可自訂。定期定額每月投入 C ÷ N，買進持有第一天投入 C，分批策略每批 C ÷ 批數。
- 入金方式：「一筆資金分批布局」（預設，C 第一天入帳）或「每月入金」（每月存入 C ÷ N，像領薪水；買進持有仍第一天投入 C、以自己的現金流算 XIRR）。
- 蓄水池：潮位定投、定期定值、乖離定投每月只釋出 B = C ÷ N；倍數低於 1 時省下的錢、減碼與超額賣出的錢存入蓄水池，倍數高於 1 時才動用蓄水池，所以不會在前幾個月就把錢花完。
- 實動資金年化：只看持股部位本身的 XIRR（買進為支出、賣出與配息為收入、期末持股為收入），用來看大多時間持現金的策略在「有投入時」的效率；平均持股比例低於 50% 時標示「🛡️ 低曝險防禦型」。
- 配息：證交所 TWT49U 除息資料（`pages-data/history/dividends.json`，每日更新）依分割比例換算後入帳；可選擇再投入。
- 成交：當日收盤價，含手續費（可打折）與證交稅；水位區間只用當日以前的資料。測試包含「截斷資料後交易不變」的未來資訊檢查。
- 指標：年化報酬（XIRR）、總報酬、時間加權最大回落、Calmar、Sharpe、平均持股比例、股利、停泊利息、手續費。勝過定期定額時才顯示 🏆，並註明是哪個指標。
- 18 種預設：經典回檔波段 7 種（含移動停利、分批停利留底倉）、智慧定期定額 5 種（含定期定額基準）、順勢動能 4 種、配置雙軌 2 種；另有最佳策略排行、滾動 1／3 年勝率與交易明細篩選。
- 「今日潮位雷達」（`radar.json`）於每次建置時由歷史檔計算，供搜尋頁篩選全部 ETF。

## 本機開發

需要 Node.js 20 以上。`npm run build:pages` 產生 `docs/`，可用任何靜態伺服器開啟。`worker/` 存放共用的頁面、樣式與前端程式（早期 Sites 版的 Worker 已不再維護）。

## GitHub Pages

工作流程於臺北時間週一至週五 18:30 依序更新 ETF 名錄、證交所歷史日 K 與大盤、央行快照與期交所 BRF 近月結算價，提交後部署 `docs/`。快照過期逾 14 天時停止該因子計分。

## Apps Script

`npm run build:gas` 產生 `gas/`。Apps Script 版與 Pages 共用同一份前端；網頁在瀏覽器直接讀 GitHub Pages 的快照（CORS 開放），讀不到時才由 `readSnapshot` 代讀（只允許名錄、總經與歷史檔路徑）。更新流程：`clasp push --force` → `clasp create-version "說明"` → `clasp update-deployment <id> -V <版號> -d "說明"`。`npm run test:gas` 檢查代讀、路徑限制與快取。

Pages 的盤中報價以只讀 JSONP 呼叫同一個 Apps Script 部署；Google 官方 ContentService 會轉址到一次性網址。只允許 ETF 名錄內代號，絕不把金鑰寫進前端、GitHub 或 API 回應。公開展示權限與富果方案額度仍須由金鑰持有人確認；服務端開關預設關閉。

## 技術指標

圖表使用 TradingView Lightweight Charts 4.1.3（與 Stock 網站相同版本），紅漲綠跌，下方為成交量（張）。

- MA5／MA20／MA60：N 根收盤價的算術平均。
- 布林通道：MA20 ± 2 倍母體標準差；%B＝(收盤 − 下軌) ÷ (上軌 − 下軌)。
- MACD：DIF＝EMA12 − EMA26，DEA＝DIF 的 EMA9，柱狀體＝(DIF − DEA) × 2。
- RSI：14 期 Wilder 平滑。
- KD：9 期 RSV，K、D 各以 1/3 平滑，首日以 50 起算。

日、週、月 K 切換後重新計算。「技術面讀數」只描述最新一根 K 棒的狀態，不參與綜合分數。價位超出歷史高低點時，延伸分可超出核心分的 0–5 上下限；加權核心分仍限制在 0–5。

## 歷史視窗、檢視模式與快取

- 圖上價格水位以最右側可見 K 棒為錨點，取該日以前 N 個日交易資料計算；週／月圖也以對應最後一日為準。上方卡片仍代表最近報價，圖下另標歷史日期。貼合畫面與雙擊可恢復自動縮放。
- 基礎檢視收合量測、籌碼、波段與權重；完整研究展開內容。三步操作教學可隨時重播；純文字控制項保留鍵盤與讀屏標籤。
- IndexedDB 僅保存公開快照，先讀舊快取再背景核對。資料變更會刷新當前標的；盤中報價獨立更新。儲存不可用或讀取過慢時回到網路來源，不將舊資料標成新行情。
- 策略尋優使用 Web Worker，失敗時分批運算，關閉時取消；相同輸入最多保留四組記憶體結果。極值保持 O(N)，多筆高低價平均改用順序統計 O(N log N)，定義與原算法一致。
- `npm run test:upgrade` 包含 ph4 公式、歷史錨點、快取故障與取消運算檢查。時間依裝置、快取與網路而異，不保證固定毫秒數。
- 右上角採搜尋、帳號與選單三個圖示；帳號視窗內整合登入、方案及外觀偏好。字級為標準／大（112%）／特大（124%），共用 CSS 編譯器統一縮放所有明確字級，並同步主圖、副圖及回測圖刻度。小字基準至少 13px，密集圖表標籤 12px；標題與價格讀數另設上限。

## 按需研究與區間成績

- 回測先看四項核心數字。「調整資金與策略條件」、「資金、風險與收支」及每張 KPI 的補充資料各自展開；完整資料與會員權限保留。摘要卡不再固定遮住平板圖表。
- 資金細節以平均持股／現金、風險量規、價差／配息／利息／成本和已實現賣出結果分組。收益分解包含未實現價差，並不等於已入袋利潤。
- 「放大查看某段時間」支援快捷日期、自訂日期、滾輪縮放和拖曳，資產與回落圖同步。區間成績用 NAV 計算時間加權報酬，排除外部入金；沿用原模擬持倉，不是重新進場回測。原全期 XIRR 保持不變；回落副圖仍以全期高點為準，區間回落另列。
- 勾選起點歸零後，三組資產曲線改畫 NAV 報酬百分比；高低點按目前顯示單位選取。差額底色僅作策略／定額曲線比較，不等於買賣訊號。
- 滾動期間以每月第一個交易日為起點，結束取滿一／三曆年後第一個可用交易日；平手獨立列出。歷史條碼可懸停、觸控或用左右鍵查看，不代表未來勝率。
- 波段幅度分布區分上漲與拉回；虛線是樣本均值，金線是目前未確認段，未確認段不混入已確認統計。日／週／月各用目前研究設定。
- 法人、融資、大戶與市場 SVG 趨勢圖支援縮放、平移及日期篩選；按「縮放與日期」展開控制。加減鍵縮放、左右鍵平移，手機保留垂直捲頁。
- 主圖三條均線可設 2–2400 期，資料不足不畫線。`npm run test:upgrade` 包含 ph5 入金中性、NAV 高低點、局部回落、缺值／平手、收支恆等式、精確 N 期參考窗和登入後巢狀控制項解鎖檢查。
